# Theme installers

Run a profile-specific wrapper from the repository root or by path:

- `bash variants/neutral/install.sh`
- `bash variants/debian/install.sh`
- `bash variants/arch/install.sh`
- `bash variants/gentoo/install.sh`

Each wrapper launches the main Sway installer with its selected profile. Set `ITSUKI_WALLPAPER_STYLE=clean` to choose the clean wallpaper; the default includes Itsuki where available.
