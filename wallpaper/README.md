# Wallpapers

The installer downloads the selected image from the public `wallpaper/` folder of [Itsuki Niri Rice](https://github.com/a43039646-svg/itsuki-niri-rice) and installs it as `~/Pictures/Wallpapers/itsuki.png`. This avoids duplicating the large image assets in this repository. A working internet connection and `curl` or `wget` are required during installation.
