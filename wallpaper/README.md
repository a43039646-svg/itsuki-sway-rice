# Wallpapers

The installer uses local images in this folder when available. Otherwise it automatically downloads the selected image from the public `wallpaper/` folder of [Itsuki Niri Rice](https://github.com/a43039646-svg/itsuki-niri-rice).

To store copies in this repository, run `bash scripts/import-wallpapers.sh`, then commit the downloaded image files. A working internet connection and `curl` or `wget` are required.
